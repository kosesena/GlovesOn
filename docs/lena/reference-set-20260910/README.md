# Lena character reference set

Created on 10 September 2026 with the built-in imagegen tool, using the existing GlovesOn Lena character as reference.

Four PNG sheets contain 22 views and states:

- **01-turnaround.png:** front, three-quarter, side and back.
- **02-gestures.png:** welcome wave, headset touch, walking, guiding, listening and confirming.
- **03-at-work.png:** carrying, unpacking, checking damage, work phone, email and recording.
- **04-expressions.png:** listening, speaking, thinking, surprised, concerned and reassuring.

These are still visual references for the user and future animation work. They are not rigged models or completed animations. Some work vignettes use a closer crop to show the task clearly. Generated rear/side costume details are inferred from the existing front reference.

The original Lena asset and live application are unchanged. Exact generation prompts are in `PROMPTS.md`.
